## Introduction
This program is designed to assist colour blind people who need to identify a certain colour in an image. Simply select an image file, click on the pixel you wish to classify the colour of, and a pop-up window will notify you of the colour.

<img width="874" height="421" alt="colour_identifier_screenshot" src="https://github.com/user-attachments/assets/acfbe961-3091-4cb4-8d40-d85d70eb976c" />


The software has been written using Python, Tkinter and PIL/Pillow.

## Run
To run the program use command:

```
python3 colour_identifier.py
```
